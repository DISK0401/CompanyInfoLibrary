# 職場情報CSVファイル


※「キー情報」以降の項目は、メタデータである。

| 通番 | 項目名 | データ型 | 説明 | 備考 |
| --- | --- | --- | --- | --- |
| 1 | 法人番号 | String | 法人番号の指定を受けた者（以下「法人番号保有者」という。）の法人番号を示すデータ項目。 |  |
| 2 | 商号または名称 | String | 法人基本情報の商号又は名称。 |  |
| 3 | 登記住所 | String | 法人基本情報の本社所在地。 |  |
| 4 | 平均継続勤務年数-範囲 | String | 職場情報の平均継続勤続年数-範囲。 |  |
| 5 | 平均継続勤務年数-男性 | String | 職場情報の平均継続勤続年数-男性。 |  |
| 6 | 平均継続勤務年数-女性 | String | 職場情報の平均継続勤続年数-女性。 |  |
| 7 | 正社員の平均継続勤務年数 | String | 職場情報の正社員の平均継続勤務年数。 |  |
| 8 | 従業員の平均年齢 | String | 職場情報の従業員の平均年齢。 |  |
| 9 | 月平均所定外労働時間 | String | 職場情報の月平均所定外労働時間。 |  |
| 10 | 労働者に占める女性労働者の割合-範囲 | String | 職場情報の労働者に占める女性労働者の割合-範囲。 |  |
| 11 | 労働者に占める女性労働者の割合 | String | 職場情報の労働者に占める女性労働者の割合。 |  |
| 12 | 女性管理職人数 | String | 職場情報の女性管理職人数。 |  |
| 13 | 管理職全体人数（男女計） | String | 職場情報の管理職全体人数（男女計）。 |  |
| 14 | 女性役員人数 | String | 職場情報の女性役員人数。 |  |
| 15 | 役員全体人数（男女計） | String | 職場情報の役員全体人数（男女計）。 |  |
| 16 | 育児休業対象者数（男性） | String | 職場情報の育児休業対象者数（男性）。 |  |
| 17 | 育児休業対象者数（女性） | String | 職場情報の育児休業対象者数（女性）。 |  |
| 18 | 育児休業取得者数（男性） | String | 職場情報の育児休業取得者数（男性）。 |  |
| 19 | 育児休業取得者数（女性） | String | 職場情報の育児休業取得者数（女性）。 |  |
| 20 | キー情報 | String | Gビズインフォが付番する一意となる識別子を示す。 |  |
| 21 | データ品質 | String | データの区分を以下のいずれかで示す。・政府承認データ・自己申告データ |  |
| 22 | 出典元 | String | データを取得したシステム名称または行政庁名を示す。 |  |
| 23 | データ取込頻度 | String | Gビズインフォへのデータ取込頻度を示す。・年次・月次・日次・半年毎 |  |
| 24 | 最終取得日 | String | データを外部システムから最後に取得した日付を示す。入力形式は以下のとおりとする。・YYYY-MM-DD（西暦-月-日） |  |
| 25 | 最終更新日 | String | Gビズインフォ上でデータが最後に更新・修正された日付を示す。入力形式は以下のとおり。・YYYY-MM-DD（西暦-月-日） |  |
