# 調達情報CSVファイル

※「キー情報」以降の項目は、メタデータである。

| 通番 | 項目名 | データ型 | 説明 | 備考 |
| --- | --- | --- | --- | --- |
| 1 | 法人番号 | String | 法人番号の指定を受けた者（以下「法人番号保有者」という。）の法人番号を示すデータ項目。 |  |
| 2 | 商号または名称 | String | 法人基本情報の商号又は名称。 |  |
| 3 | 登記住所 | String | 法人基本情報の本社所在地。 |  |
| 4 | 受注日 | String | 調達情報の認定日。 |  |
| 5 | 件名 | String | 調達情報の活動名称。 |  |
| 6 | 落札価格 | String | 調達情報の活動金額。 |  |
| 7 | 組織名 | String | 調達情報の公表組織。 |  |
| 8 | 備考 | String | 備考 |  |
| 9 | キー情報 | String | Gビズインフォが付番する一意となる識別子を示す。 |  |
| 10 | データ品質 | String | データの区分を以下のいずれかで示す。・政府承認データ・自己申告データ |  |
| 11 | 出典元 | String | データを取得したシステム名称または行政庁名を示す。 |  |
| 12 | データ取込頻度 | String | Gビズインフォへのデータ取込頻度を示す。・年次・月次・日次・半年毎 |  |
| 13 | 最終取得日 | String | データを外部システムから最後に取得した日付を示す。入力形式は以下のとおりとする。・YYYY-MM-DD（西暦-月-日） |  |
| 14 | 最終更新日 | String | Gビズインフォ上でデータが最後に更新・修正された日付を示す。入力形式は以下のとおり。・YYYY-MM-DD（西暦-月-日） |  |
